15.2Troubleshooting

A tool says the genome is not set. Choose File → Manage Database…, add the genome FASTA as FASTA DNA and click Set as reference genome. BLAST, MSA Extend, TE-Aid, boundary prediction (Genome Cov) and the genome plots need it.

RepeatMasker, FastGA, HISAT2, FastME or FastTree is not found. They are not bundled. Install them into a conda environment (see Installation), enter that environment in File → Setting → General → External tools, and click Test. On Windows they must be in a WSL2 environment.

BLAST or Repeat Quantify is very slow. Check the word size: small values are much more sensitive and much slower on repetitive genomes. For Repeat Quantify, 11 is a good BLASTn default and 7 can make it hang. Also check Threads for the UI in File → Setting → General → Performance: a high value leaves few threads for the tools.

Minimap2 misses hits inside a satellite array. minimap2 ignores its most frequent seeds. In Mapping → Advanced Settings, set repetitive seeds to Keep more.

A mapping gives differences at 100 % identity. The reference has two records with the same name. Give every record a unique name.

A job cannot be stopped at once. Stop in the status bar cancels the running job; external programs may take a moment to end.

An HTML report is blank in Preview. Use Open in browser in the Preview title bar.

New outputs are not visible. Press F5 to refresh, and check that you are looking at the folder of the input: outputs go there.

A Repeat Quantify report says a name appears twice in the library. Two records share a name; their hits were merged into one row. Rename them.

macOS refuses to open the app. For an unsigned build, right-click the app, choose Open, and confirm. This is needed only the first time.

Reporting a bug. File → Setting → General → Diagnostics → Copy diagnostics copies the version, system and folder locations. Switch on Verbose logging, repeat the problem, and attach the file from Open log file. For failed Tree and Mapping runs, attach the _failed.log next to the input.

15.3Citation

If RepeatViewer contributes to your work, please cite:

Qian J, El-nagish A, Szatkowski S, Maiwald S, Sultana N, Costard D, Rudzinski A, Schmidt N, Heitkam T. 2026. RepeatViewer: a platform for explorative analysis of repetitive DNAs. bioRxiv, https://doi.org/10.64898/2026.11.23.768287

Please also cite TEtrimmer (Nature Communications, 2025) where its methods are used. Tool reports (Tree, Mapping, Primers) include a methods paragraph and the references of the programs they ran; cite those programs too.

15.4Bundled programs

BLAST+, MAFFT, MUSCLE, minimap2 and IQ-TREE are distributed with RepeatViewer under their own licences. The NOTICE.md file next to each program in repeatviewer/backends/ gives its licence and source.
